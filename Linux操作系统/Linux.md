### 基础知识

- 先理解 Linux 如何支撑一个服务 一次请求进入服务器，大致会经过
 ```
网卡接收数据
  → 内核网络协议栈
  → Socket 接收队列
  → 应用线程获得 CPU
  → 读取内存、文件或调用下游
  → 返回响应
```

任何一环排队，都可能导致响应变慢。SRE 需要掌握以下基础：

| 知识 | 必须理解的内容 | 对排障的帮助 |
|---|---|---|
| 用户态与内核态 | 应用通过系统调用访问内核功能 | 区分计算开销与系统调用开销 |
| 进程与线程 | 地址空间、线程共享资源、调度和信号 | 定位热点线程、死锁及异常退出 |
| 虚拟内存 | 匿名页、文件页、缺页、回收、Swap | 分析内存增长、抖动和 OOM |
| 文件系统 | 文件描述符、inode、目录项、页缓存 | 分析空间不足、文件泄漏和写入延迟 |
| 网络 | TCP 状态、连接队列、重传、路由、DNS | 分析连接失败和请求超时 |
| 资源隔离 | namespace、cgroup | 解释容器内外指标为何不同 |
| 服务管理 | systemd、日志、启动依赖、资源限制 | 分析服务启动失败和反复重启 |
